# PPC930

O agente detecta candidatos USB/serial no sistema operacional, mas não tenta ler cartão diretamente. Use `scripts/diagnose_ppc930.ps1` no Windows ou `scripts/diagnose_ppc930.sh` no Linux para obter VID/PID, COM/device e driver.

Detecção USB bem-sucedida não significa que o TEF está homologado. O teste financeiro real só será habilitado depois da biblioteca e parametrização oficiais da integradora.
